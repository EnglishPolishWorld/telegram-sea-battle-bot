# Морской бой с Псом — Telegram Sea Battle Bot

Полноценный морской бой внутри Rich Message Telegram — без Mini App. Поле состоит из callback-кнопок: пользователь нажимает клетку, бот отмечает промах или попадание, выполняет ответный ход и редактирует то же сообщение.

## Моя роль

Проект создан в основном с помощью AI coding tools. Я пошагово задавал механику и ожидаемое поведение, разбивал новые функции на этапы, запускал версии, тестировал игровой процесс, воспроизводил ошибки и направлял последующие исправления.

Я **не представляю код как полностью написанный вручную мной**. Этот проект показывает мой подход к AI-assisted prototyping, ручному тестированию, игровой логике и последовательной отладке.

## Возможности

- три размера поля: 6×6, 8×8 и классическое 10×10;
- ручная и случайная расстановка кораблей;
- ответный огонь с логикой поиска соседних клеток после попадания;
- переключение между полем противника и собственным флотом;
- награды за победу, магазин расходников и постоянный инвентарь;
- статистика, точность, серии побед и рейтинг;
- личные чаты, группы, inline-режим и Guest Mode;
- сохранение партий и статистики в SQLite;
- Docker/Railway-ready deployment;
- отдельные тесты игровой логики.

## Технологии проекта

`Python` · `Telegram Bot API / Rich Messages` · `SQLite` · `Docker` · `Railway` · callback UI · unit tests · AI coding tools

## Переменные окружения

- `BOT_TOKEN` — токен BotFather;
- `DATABASE_PATH` — путь к SQLite базе;
- `CACHE_CHAT_ID` — необязательный чат для кэширования сцен inline-партий.

Команды: `/start`, `/new`, `/group`, `/shop`, `/stats`, `/top`, `/rules`, `/creator`.
