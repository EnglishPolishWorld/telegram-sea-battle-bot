# Карточный Пёс
Карточная игра Go Fish полностью внутри Rich Message Telegram. Игрок и пёс
получают по 7 карт из колоды в 36 карт. Карты игрока открыты и кликабельны,
карты пса показаны рубашкой. Нажатие своей карты запрашивает у пса весь её ранг.

## Railway
Создайте сервис из этого репозитория и добавьте переменную `BOT_TOKEN`. При необходимости добавьте `DATABASE_PATH=/data/cards.sqlite3` и Volume в `/data`.

Команды: `/start`, `/creator`.
