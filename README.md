# Сундучки с Псом
Карточная игра «Сундучки» полностью внутри Rich Message Telegram. Игрок и пёс
получают по 7 карт из колоды в 36 карт. Карты игрока открыты и кликабельны,
карты пса показаны рубашкой. Нажатие своей карты запрашивает у пса весь её ранг.

В обычных чатах бот динамически рисует цельную игровую сцену: пиксельный стол,
собаку с одной из восьми эмоций, руки игрока и именно те карты, которые сейчас
находятся в его руке. Под сценой Rich Message показывает отдельные понятные
кнопки для запроса каждой имеющейся карты.

Графическая сцена также работает в группах при запуске через inline-режим
`@имя_бота`: динамическое изображение предварительно загружается в Telegram и
вставляется в Rich Message по `file_id`.

Поддерживается Telegram Guest Mode: после включения гостевых запросов для бота
игру можно вызвать в группе, даже если бот в неё не добавлен. Бот отвечает на
`guest_message` через `answerGuestQuery`; кнопки продолжают редактировать то же
игровое Rich Message.

Перед партией можно выбрать лёгкую, среднюю или сложную игру. За победу
начисляется 5, 10 или 15 монет соответственно. В магазине доступны постоянные
расходники: подсказка «Нюх», двойной добор и защита от следующего хода пса.

## Графические карты без Mini App
Бот умеет создать собственный набор из 36 статических custom emoji размером
100×100 и показывать их непосредственно внутри кликабельных кнопок Rich Message.
Создатель бота один раз отправляет `/setupcards` в личном чате. Набор создаётся
через Bot API, а соответствие карт и `custom_emoji_id` сохраняется в SQLite.
Если графические ID ещё не настроены, игра автоматически использует обычные
Unicode-карты. Для использования custom emoji владельцу бота нужен Telegram
Premium (либо подходящее дополнительное имя пользователя с Fragment).

## Railway
Создайте сервис из этого репозитория и добавьте переменную `BOT_TOKEN`. При необходимости добавьте `DATABASE_PATH=/data/cards.sqlite3` и Volume в `/data`.

Команды: `/start`, `/new`, `/group`, `/shop`, `/stats`, `/top`, `/rating`, `/creator`, `/setupcards`.
