# Telegram Visual Ban Bot

Простой Telegram-бот с одной inline-кнопкой «🚫 Бан».

После нажатия бот просит ввести `@username причина` и отправляет визуальное сообщение:

🚫 Пользователь @username был забанен.
👮 Администратор: Собачья Душа
📝 Причина: причина

**Важно:** бот никого реально не банит и не изменяет права пользователей.

## Запуск

Переменная окружения:

- `BOT_TOKEN` — токен бота из BotFather.

Запуск:

```bash
python bot.py
```
