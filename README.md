# Карточный Пёс
Карточная игра Go Fish полностью внутри Rich Message Telegram. Используется
колода из 36 карт (от шестёрок до тузов); каждая карта представлена отдельной
текстовой кнопкой с рангом и мастью.

## Railway
Создайте сервис из этого репозитория и добавьте переменную `BOT_TOKEN`. При необходимости добавьте `DATABASE_PATH=/data/cards.sqlite3` и Volume в `/data`.

Команды: `/start`, `/creator`.
